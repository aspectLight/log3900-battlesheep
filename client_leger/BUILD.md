# Build Flutter APK

## Prerequisites

- Flutter SDK installed
- Android SDK configured

## Steps

```bash
# 1. Get dependencies
flutter pub get

# 2. Build release APK
flutter build apk --release
```

## Output

The APK will be at:

```
build/app/outputs/flutter-apk/app-release.apk
```

## For Submission

Rename the APK or zip it as `ClientLeger.zip`.
