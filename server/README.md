# Serveur - Déploiement Local

## Prérequis

- Node.js v18+
- npm v9+

## Installation et Démarrage

```bash
npm install
npm run start
```

Le serveur sera disponible à `http://localhost:3000`

## Services Cloud

Les services suivants sont hébergés dans le cloud et resteront actifs jusqu'à la transmission des notes finales :

- **MongoDB Atlas** - Base de données
- **Firebase** - Authentification
