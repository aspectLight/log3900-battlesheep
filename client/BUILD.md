# Build Electron Executable

## Prerequisites

- Node.js v18+
- npm installed

## Steps

```bash
# 1. Install dependencies
npm install

# 2. Build the executable
npm run build:electron
```

## Output

The executable will be in the `build/` folder:

```
build/
└── client-win32-x64/
    └── client.exe
```

## For Submission

Zip the entire `client-win32-x64/` folder and rename to `ClientLourd.zip`.
